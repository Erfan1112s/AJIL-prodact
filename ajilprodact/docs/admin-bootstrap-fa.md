# ساخت امن حساب مدیر

این ابزار حسابی با نام کاربری `admin` و نقش `SUPER_ADMIN` می‌سازد. رمز عبور در ترمینال نمایش داده نمی‌شود و فقط هش آن در پایگاه داده ذخیره می‌شود. حساب‌های موجود را بازنویسی نمی‌کند و درج هر دو رکورد مدیر و کاربر یکپارچه را در یک تراکنش انجام می‌دهد.

## پیش‌نیازها

- Node.js نسخه ۲۰٫۹ یا جدیدتر
- دسترسی شبکه به MySQL و وابستگی‌های نصب‌شده پروژه
- اجرای migration شماره `006-unified-users.sql` روی پایگاه داده هدف
- تنظیم متغیرهای `DB_HOST` (اختیاری)، `DB_PORT` (اختیاری)، `DB_USER`، `DB_PASSWORD` و `DB_NAME` در محیط اجرا

## اجرا

روی میزبان امن و در ترمینال تعاملی، با متغیرهای محیطی دیتابیس production:

```sh
node --env-file=.env scripts/bootstrap-admin.mjs
```

رمز قوی و یکتای حداقل ۱۶ نویسه را دو بار وارد کنید. رمز نمونه `admin1234` برای production پذیرفته نیست. رمز را در دستور، فایل source، لاگ یا مخزن Git قرار ندهید. پس از ساخت، با نام کاربری `admin` وارد `/admin/login` شوید.

اگر نام کاربری از قبل در یکی از جدول‌های `admin_users` یا `users` باشد، ابزار متوقف می‌شود و آن حساب را تغییر نمی‌دهد. برای تغییر رمز یک مدیر موجود، از مسیر امن مدیریت رمز در محیط استقرار استفاده کنید؛ این ابزار برای بازنشانی حساب نیست.

این ابزار migration یا schema را اجرا نمی‌کند و هیچ جدول یا رکورد موجودی را حذف نمی‌کند. اگر اجرای تراکنش شکست بخورد، درج‌های مربوط به حساب rollback می‌شوند.
